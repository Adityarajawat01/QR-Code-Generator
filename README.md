# QR Code Generator 🚀

A simple, fast, and efficient web application to generate customizable QR codes instantly from text, URLs, or contact information. Built using clean HTML, CSS, and lightweight JavaScript.

## 🌟 Features

* **Instant Generation:** Generates QR codes in real-time as you type or paste your link/text.
* **Versatile Input Support:** Seamlessly handles standard text, website URLs, and contact info.
* **Clean & Responsive UI:** Fully responsive design that looks great on both desktop and mobile devices.
* **Lightweight:** Fast loading speeds with zero unnecessary dependencies.

## 🛠️ Tech Stack

* **HTML5:** Semantic structure of the web application.
* **CSS3:** Clean styling and modern layout layout rules.
* **JavaScript:** Dynamic QR code generation logic.
